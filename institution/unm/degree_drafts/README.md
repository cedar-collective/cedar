# Compiled degree boards

Generated by `scripts/compile-degree-interpretations.R --write`; do not edit by
hand. Each board here takes the place of the hand-built board with the same
catalog id on Degree Explorer, labelled a draft until the reading it was
compiled from (`degree_drafts.csv`) is signed off in Admin > Catalog Review.
The hand-built files one folder up are not changed. See
[Publishing a compiled board](../../../docs/developers/catalog-normalization.md#publishing-a-compiled-board).
