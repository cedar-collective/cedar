# Catalog interpretation drafts

These are AI-assisted, unapproved interpretations of the complete captured
2026–2027 pilot program records. Codex authored them in the CEDAR development
session on 2026-10-19; no API request was used. Read each file's `producer`,
`scope`, version, catalog ID and unit key. Linked course prerequisite units are
not included in this initial program/concentration pilot.

CEDAR stages these files automatically in Admin > Data & Usage > Catalog Review
> Program review, after verifying the matching prepared source packet and source
archive. Every source passage has a coverage decision and every rule cites exact
captured text. Cases deliberately retain ambiguities/conflicts; no file implies
human academic approval or changes the semester planner.

Keep v1 when adding `program.v2.json`. Git provides authored-data diffs; immutable
staged proposals and attributed review revisions live in the separate review
store. Do not copy approval status into these drafts. Source, prompt or schema
changes require a matching new unit key and interpretation.

See [the full workflow](../../../docs/developers/catalog-normalization.md).
