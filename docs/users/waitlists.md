# Waitlists
{: .fs-9 }

**Students waiting for seats in full courses**
{: .fs-6 .fw-300 }

---

Waitlists inspects students on course waitlists by course, declared program, and student classification. It lives under **Registration → Waitlists** and can also be opened from Regstats waitlist links.

The tab is best for checking where demand is visible in Banner waitlist records. It should not be read as total unmet demand: students who wanted a course but never joined or remained on a waitlist are not visible here.

---

## Filters

Set the filter stripe, then click **Inspect Waitlists**.

| Filter | What it controls |
|---|---|
| **Campus / College / Department** | Limits courses included in the inspection. |
| **Level** | Limits by course level. |
| **Term** | Accepts exact term codes or term-type values. |
| **PoT** | Limits by part of term. |
| **Course** | Limits to one or more subject-course values. |

You must select at least a course or a term before running the inspection.

---

## Views

| View | What it shows |
|---|---|
| **Course Overview** | Unique waitlisted students per course. |
| **By Program** | Declared program codes for students waiting for each course. |
| **By Classification** | Academic classification of students waiting for each course. |

Course links can be used to re-run the Waitlists view for that specific course and term.

---

## Methodology Notes

{% include definition-summary.html id="waitlist" %}

Program and classification values come from student enrollment records. They are useful for context, but they may not fully explain why a student needs the course.
